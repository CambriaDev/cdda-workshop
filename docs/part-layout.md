# 0.3.0 部件详情与比较

## 信息层级

名称、部件 ID、可靠简介及来源 → 用途标签与额定值提示 → 用途核心参数／功能 → 已记录实例状态（仅车上实例）→ 折叠的其它参数与底层物品能力 → 折叠的高级公共定义与来源。

展示规则只组织既有详情模型，不改变游戏数据、性能计算、存档或项目协议。未知与未提供不等于零；默认零值移到次要参数，而非删掉。额定值不是实测性能，当前实例储量不是额定容量。

## 用途与核心顺序

| 主用途 | 优先内容 |
| --- | --- |
| 发动机／动力源 | 输出与马力、能源种类／可选燃料、满载能耗、重量 |
| 交流发电机 | 发电功率、机械功率及马力占用、重量 |
| 环境发电 | 发电功率及条件说明、重量 |
| 反应堆 | 发电功率、已解析燃料及容量、重量 |
| 电池 | 额定储量／单位、已有充电参数、重量 |
| 液体储罐 | 分口袋容量、防漏液／气密等条件、重量限制、重量 |
| 车载武器 | 已解析弹药容量／能源需求、重量与耐久 |
| 车轮／旋翼 | 几何尺寸、滚阻及越野参数／有效直径、重量与耐久 |
| 照明与信号 | 耗电、已有亮度或音量参数 |
| 电器与工具 | 固定耗电／操作能耗说明、伪工具及能力等级／部件能力／兼容工具、容量 |
| 乘员与寝具 | 已有舒适、保暖及安全参数、容量、重量 |
| 防护／结构 | 耐久、已有防护／对外碰撞参数、安装层、重量 |
| 货物储存 | 货舱容积、货物重量修正、重量 |
| 未分类兜底 | 已解析能源、容量与能力、重量与耐久，再看其余参数 |

采用可信标志、底层物品类型和明确用途分类，不猜测 ID 或翻译名称。`movement`、`energy` 等宽泛分类不能证明具体性能。`BOARDABLE` 只说明可站立，不能单独证明座椅；`MOUNTABLE` 也不能单独证明电器。

支持复合用途。主用途按上表顺序确定，其它用途的重点在后面合并、字段去重；电器上的货舱不会让重量重新抢到前面。工具能力数量、JACK／LIFT 起重等已由能力列表清楚表达时，不再重复铺一组计数行；未知能力信息仍保留。

固定耗电不等于操作总能耗，伪工具可能另需供电、充能和启用条件。满载燃料能量输入不是 L/h，不推算实际油耗。多口袋与互斥弹药容量不虚构总数；连接兼容不代表已经安装或能够使用。

## 比较与修改边界

- A 跟随部件库选择，安装按钮始终安装 A 到当前格。
- 默认右列展示当前格的安装顺序及所选实例，可拆除、改外观；实例状态与额定参数分开。
- “将当前部件设为对照 B”将 ID 固定在 B，然后选择另一个部件作为 A。可以替换、清空 B，或切回实例模式；B 没有安装或实例修改入口。
- 搜索、筛选和模式切换不替换 B。比较选择不写入项目、导出及撤销历史，刷新页面后不恢复。
- 数据组合变化后重新查当前定义；缺失 B 保留 ID 并明确提示，不展示已失效的旧定义。重新启用相应模组后按当前定义恢复。
- 同类核心内容顺序稳定；不强制跨类型字段逐行对齐，也不计算无法可靠判断的优劣或实际性能差值。

## 屏幕与操作

- ≥1440px：部件库、画布、右侧双列面板；每列至少约 280px。
- 768–1439px：双列面板放在画布下方。
- <768px：用 A／车上实例或 A／B 按钮切换阅读，不横向压缩两列。按钮可通过 Tab 和空格／回车操作并有选中状态。
- 两列独立滚动，换一列部件不重置另一列；同格安装列表限高滚动，避免挤掉详情。

自动化覆盖及未验证边界见验收记录；浏览器回归不等于真实游戏或容器启动验收。
