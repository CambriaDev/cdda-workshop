### 复现

在项目根目录执行：

```powershell
npm ci --legacy-peer-deps
npm run check
npm test
npm run build
npm run test:e2e
npm audit --audit-level=low
```

普通测试不读取私人世界。0.1.0 的 98 项全部通过记录包含一次私档 opt-in；本次 0.3.0 在未设置私档路径的环境运行，206 项通过、1 项按设计跳过。只有显式设置 `CDDA_PRIVATE_SAVE_DIR`（以及可选 `CDDA_PRIVATE_EXPECTED_VEHICLES=2`）才执行私档回归；跳过不代表隐式访问。

## 部件详情专项证据

- 单元回归49项：真实 alternator_car 发电780 W／机械负载1492 W（约2.001 hp），electric_small 额定7040 W／满载8000 W；crane_tiny 的 JACK1／LIFT1 各额定500 kg；SELF_JACK 不换算通用起重能力。
- 真实 blazemod 的裸整数 epower=-1 按源码解释为1 kW固定耗电；共享领域读取器与整车额定统计保持一致。非法小数数字或不支持的功率单位不冒充可靠数值。
- 60 L油箱来自基础物品口袋，不误用货舱size；多口袋逐个列出、不虚构总容量；弹药替代、多弹匣井及按份计量物品保守未知。容量详情不扩张原有燃料补满能力。
- 部件工具能力、基础物品能力、伪工具与允许连接工具分别标注；底层带电能力仅为额定条件信息，不表示当前可用。没有将角色技能／安装要求与工具能力混淆。
- UI回归验证描述与高级定义文本转义、无HTML执行；缺失实例字段不补0/false，大整数储量保持原词元，输入不被修改。待安装与已安装详情独立选择。
- 静态额定值不是当前实测：损伤、老化、风光条件、转速、负载与整车净功率不模拟。未知、未提供与源码默认分别标注；完整公共定义仅在高级区作可追溯兜底。
- Docker CLI在本环境不可用，未执行容器启动验收；本次构建与浏览器验证是生产静态产物验证，不是容器运行或实际游戏验收。

## 0.3.0 布局与对比专项

- 43 项纯布局测试：已知用途与复合用途去重、可靠字段判断、默认零值降级、未知重点保留、全部详情字段归属、真实核心／模组数据；不按 ID、名称或功率正负猜类别。
- 10 项 UI 测试：电器耗电→功能→容量的 DOM 顺序，重量／体积／防护折叠，完整可靠简介及底层描述兜底，转义、双语能力语义、额定提示、实例插槽与对照 testId。
- 纠正易混淆标志：普通货舱的 BOARDABLE 不使它变座椅，床的 MOUNTABLE 不使它变电器；门／屋顶／窗及宽泛分类保守处理。
- 两列只读对照状态不写项目／导出／撤销栈；安装始终使用 A。相同 ID 有提示，缺失 B 保留 ID 并在模组恢复后按当前定义解析；不冒充旧数据。
- 宽屏双列在右侧，中屏移到下方，手机按钮切换；独立列滚动、不出现页面横向溢出。用途顺序与交互边界见 [部件布局说明](part-layout.md)。
- 没有新增油耗、续航、武器或整车物理模拟，领域详情读取与只读存档协议保持不变。

## 明确未完成 / 未证明

1. **真实游戏验收尚未执行。** 本地未找到匹配 0.I-1 的游戏可执行文件。模板加载、蓝图模组启用与调试生成、实际角色成长和装备行为、多个模组组合的游戏运行兼容均不能由浏览器 / Schema 测试替代。
2. **健康默认策略未按原计划完全实现。** 当前有限健康重置为显式 opt-in，默认关闭；只恢复已有 hp_max 和已审查的临时状态，永久 / 未知 effects 保留。不会宣称完整治愈、重算全部突变 / CBM 生命值或处理任意模组疾病。此偏离在界面与兼容报告明示。
3. **复杂补满不臆造。** 只补能严格证明容量与结构的单 MAGAZINE 口袋；体积油箱、多口袋、可拆弹匣等保留原值并警告，不能声称整车全部全新化完成。
4. **不是完整游戏加载器或物理模拟器。** 未支持继承规则按字段标记不完整；实际功率、全运行载重规则、材质 / 附件 / 异常口袋的某些统计缺失以已知小计和缺失计数显示。
5. **不支持目标存档注入。** 无损项目只由本应用回读，蓝图不是完整存档快照；高级背包 / NPC / 地图编辑入口明确施工中。
6. **版本边界。** 私档格式 33 与核实源码格式 36 不同；解析和不修改回归成功不代表跨版本游戏导入安全。
