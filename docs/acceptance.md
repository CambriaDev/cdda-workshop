### 复现

在项目根目录执行：

```powershell
npm ci --legacy-peer-deps
npm run check
npm test
npm run build
npm run test:e2e
npm audit --audit-level=low
```

普通测试不读取私人世界；包含上述私档计数的 98 项结果需显式设置 `CDDA_PRIVATE_SAVE_DIR`，以及可选 `CDDA_PRIVATE_EXPECTED_VEHICLES=2`。未设置时相应私档用例会跳过，属于预期，不代表隐式访问。

## 明确未完成 / 未证明

1. **真实游戏验收尚未执行。** 本地未找到匹配 0.I-1 的游戏可执行文件。模板加载、蓝图模组启用与调试生成、实际角色成长和装备行为、多个模组组合的游戏运行兼容均不能由浏览器 / Schema 测试替代。
2. **健康默认策略未按原计划完全实现。** 当前有限健康重置为显式 opt-in，默认关闭；只恢复已有 hp_max 和已审查的临时状态，永久 / 未知 effects 保留。不会宣称完整治愈、重算全部突变 / CBM 生命值或处理任意模组疾病。此偏离在界面与兼容报告明示。
3. **复杂补满不臆造。** 只补能严格证明容量与结构的单 MAGAZINE 口袋；体积油箱、多口袋、可拆弹匣等保留原值并警告，不能声称整车全部全新化完成。
4. **不是完整游戏加载器或物理模拟器。** 未支持继承规则按字段标记不完整；实际功率、全运行载重规则、材质 / 附件 / 异常口袋的某些统计缺失以已知小计和缺失计数显示。
5. **不支持目标存档注入。** 无损项目只由本应用回读，蓝图不是完整存档快照；高级背包 / NPC / 地图编辑入口明确施工中。
6. **版本边界。** 私档格式 33 与核实源码格式 36 不同；解析和不修改回归成功不代表跨版本游戏导入安全。
